# DB skripta (Adminer / MonsterASP.NET)

`setup.sql` samo kreira novu tabelu `SupportTickets` (sistem za podršku/tikete).

1. Prijaviti se u Adminer panel za `db42634`.
2. Otvoriti tab **SQL command**.
3. Zalijepiti sadržaj `setup.sql` i pokrenuti (Execute) jednom.

Kad god se doda nova tabela/kolona u budućnosti, ovdje se doda odgovarajući
`CREATE TABLE` / `ALTER TABLE` za tu izmjenu.
